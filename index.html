FAQ FrikChange

Les réponses essentielles avant de publier ou débloquer un contact.

Comment publier ?

Créez votre compte, renseignez l'annonce puis envoyez-la. Une annonce passe en validation avant d'être publique.

Quand le WhatsApp est-il visible ?

Le numéro reste masqué dans la place de marché. Il est retourné uniquement après une transaction confirmée pour l'annonce concernée.

Comment fonctionne le parrainage ?

Le code présent dans votre lien est associé au nouveau compte. Une transaction réussie d'un filleul déclenche 30% de commission.

Que faire si le paiement tarde ?

Le retour de paiement ne suffit pas à débloquer le numéro : le webhook Chariow confirme la vente côté serveur.
